02

What you'll be doing — the 5-stage workflow

Never skip a stage

Every procurement item moves through five stages, then routes to Rob for a decision. Each stage has a required deliverable that must exist before the next stage begins. The item's Stage field in Zoho always reflects current state.

STAGE 1

Spec

Build the RFQ spec sheet — dimensions (in + mm), materials, finish, performance, 120V/UL-ETL, compliance certs, warranty. Florida overlays baked in.

Out: Spec sheet + Est. Item Spend set
→
STAGE 2

Bid

Minimum 3 quotes, identical RFQ packet, DDP only (reject FOB). Collect factory audit, US references, sample policy, terms. Run ImportKey on every vendor. Log every touch.

Out: ≥3 normalized bids logged
→
STAGE 3

Level

Convert every bid to true landed cost — freight, duties (verify HTS), broker, drayage, FX ±5%, QC, defect allowance. Yellow-cell every assumption. Cost-per-year vs. US baseline.

Out: Leveled cost spreadsheet
→
STAGE 4

FL-Validate

Apply the Florida checklist (Section 03) to each bid — humidity, salt air, hurricane code, electrical. Log pass/fail per vendor. Fails are auto-rejected.

Out: Pass/fail per vendor
→
STAGE 5

Recommend

One-page decision summary, single recommended vendor. Submit to Rob by advancing the Stage. Sample in hand for $25K+ items.

Out: Decision package → Rob
Submitted → ✓ Approved ≈ Approved w/ Conditions ✕ Declined ? Need More Info
03

The Florida gates (Stage 4)

Applied to every item by default

💧 Humidity (all 9 properties, 75%+ RH)

No bare particleboard/MDF below 36" — marine ply or solid hardwood. Mattress foam ≥1.8 lb/ft³, CertiPUR-US/Greenguard. Cabinet hardware solid brass/stainless/zinc — never plated steel. Damp-rated bath lighting min.

🌊 Salt air (Jax W, Jax N, St. Augustine)

Stainless 316 on exposed hardware — 304 pits within 18 months. Outdoor furniture: powder-coated aluminum or marine-grade poly. No exposed ferrous metal.

🌀 Hurricane code

Coastal (Jacksonville, St. Augustine): 140 mph wind rating on exterior signage/fixtures. Inland: typically 130 mph. Confirm against the property's CO zone.

⚡ Electrical (insurance-critical)

120V/60Hz ONLY. UL or ETL listing REQUIRED — "equivalent" certs not accepted. NEMA 5-15P plug. GFCI compatibility for bath/exterior. 220V or non-UL = automatic reject.

⛔ Automatic rejection — these never reach Rob

  • FOB compared to DDP without normalizing
  • "Premium / hotel grade / luxury" with no numerical specs
  • No physical sample on first order
  • Particleboard or MDF below 36" in Florida
  • 220V appliances or non-UL/ETL electrical
  • Single overseas vendor with no Plan B
  • Verbal / WhatsApp pricing — must be in writing, ≥30 days
  • HTS tariff exposure not addressed
  • Assumptions hidden inside clean numbers (yellow cells required)
  • Decision logged anywhere but the Zoho record
